# TypeFix

TypeFix is a lightweight Windows utility that instantly fixes text typed with the wrong keyboard layout between Arabic and English.

أداة خفيفة لنظام ويندوز تقوم بتصحيح النصوص المكتوبة بتخطيط لوحة مفاتيح خاطئ بين العربية والإنجليزية فوراً.

## Features | المميزات

* Arabic ↔ English keyboard layout conversion

* Convert selected text with a hotkey

* Lightweight and fast

* Runs on Windows

* No internet connection required

* تحويل الكتابة بين العربية والإنجليزية

* تحويل النص المحدد باختصار لوحة مفاتيح

* خفيف وسريع

* يعمل على ويندوز

* لا يحتاج إلى اتصال بالإنترنت

## Example | مثال

Wrong text:

```text
hgsghl ugd;l
```

Converted text:

```text
السلام عليكم
```
